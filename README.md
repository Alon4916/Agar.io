
# Mini Agar.io 

Mini Agar.io Mejorado es un juego inspirado en **Agar.io**, desarrollado en **Python** usando **Pygame**.  
Controla tu célula, come comida, divide células hijas y sobrevive contra bots inteligentes en un mundo dinámico.

---

## 🎮 Controles
- **Mouse:** Mover jugador  
- **SPACE:** Dash (aumenta velocidad temporalmente, pierdes 5% de masa)  
- **Q:** Dividir célula (la célula hija se separa y puedes controlarla)  
- **E:** Expulsar masa (crea comida que puedes dejar atrás)  
- **ESC:** Salir del juego  

---

## 🕹 Objetivo del juego
- Comer comida y células más pequeñas para crecer.  
- Evitar ser devorado por bots más grandes o células enemigas.  
- Dividirse estratégicamente para escapar o capturar enemigos.  
- Sobrevivir hasta eliminar todos los bots y ganar la partida.  

---

## ⚙ Requisitos
- **Python 3.10 o superior**  
- **Pygame 2.3.0**  

---

## 💻 Instalación
Instala Python 3.10+ desde [python.org](https://www.python.org/).  
Instala Pygame ejecutando:  
pip install pygame
Descarga el archhivo main.py de github
Disfruta del juego
